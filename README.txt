World Radio v1.0.0

WWR / WWR-EUTR service selector. Existing radio sites are unchanged.
Open index.html via a static web server, or publish this folder with GitHub Pages.
The featured buttons switch the introduction; service links open the corresponding radio website.
The last selected service is remembered only in this browser's localStorage.
WWR-EUTR game integration requires the local bridge and ETS2 plugin.
Version policy: increment the patch version with each applied update.
